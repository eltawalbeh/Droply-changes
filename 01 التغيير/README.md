# 01 التغيير

## الهدف
تهيئة الأساس الأولي للمشروع حسب خطة Droply الحالية.

## التغييرات
- Desktop-first Station Admin shell
- React + TypeScript + Vite
- Supabase-ready structure
- إزالة أي demo data / fake analytics / simulated actions
- تجهيز routes الأساسية للإدارة
- تجهيز domain types الأولية

## طريقة التطبيق على المشروع الأصلي
انسخ كل ملف من هذا المجلد إلى نفس الـ path داخل مشروع Droply الأصلي.

مثال:
- `01 التغيير/src/App.tsx` → `src/App.tsx`
- `01 التغيير/src/lib/supabase.ts` → `src/lib/supabase.ts`
- `01 التغيير/package.json` → `package.json`
